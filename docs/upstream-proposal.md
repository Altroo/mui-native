# Upstream collaboration proposal draft

Status: draft, not submitted.

We are developing an independent React Native compatibility layer for Material UI and MIT-licensed MUI X Community. It prioritizes existing application APIs and theme configuration while using native rendering on iOS and Android and original MUI on web.

We would like feedback on the compatibility contract and whether small, independently useful changes that separate platform-independent logic from DOM rendering would be welcome upstream. We will first provide a running catalog, measured limitations, license provenance and native tests. We do not propose merging an entire experimental native runtime into MUI without maintainer agreement.

The project excludes Pro/Premium code and paid-only feature parity, uses independent branding, and does not imply endorsement. Upstream acceptance is optional; independent development can continue under the applicable licenses.

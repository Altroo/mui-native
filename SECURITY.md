# Security

Do not put credentials, personal data, or exploit details in a public issue. Use [Report a vulnerability](https://github.com/Altroo/mui-native/security/advisories/new) to submit a confidential report to the maintainer through GitHub. Include a minimal reproduction, affected commit or package version, impact and any workaround.

The upstream monitor tracks published npm advisories as well as source changes. Reused source needs independent review because dependency scanners cannot identify every copied-code vulnerability. Automated candidates never publish or receive release secrets.

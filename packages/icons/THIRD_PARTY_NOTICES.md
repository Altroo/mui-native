# Material Icons attribution

This package adapts all 10,750 icon modules published in `@mui/icons-material` 9.5.0. The source archive and every module hash are recorded in `upstream/material-icons.json` in the source repository. Its archive integrity is checked before generation.

The React wrapper source is MIT licensed, Copyright (c) 2014 Call-Em-All. The exact upstream MIT notice follows below. The upstream package README identifies the artwork as Google's Material Icons. Google distributes Material Icons under Apache License 2.0; that license is retained in `LICENSE.material-icons` as additional artwork attribution. The primary license source is <https://github.com/google/material-design-icons/blob/master/LICENSE>.

Generated modules preserve the published path data, element order, arrays, React keys, fragments, groups, opacity and other SVG attributes. Imports and React element construction are adapted to the native Material SvgIcon factory. These changes do not add Material Symbols, new artwork or invented variants. Legacy brand and alias exports remain as supplied in the pinned MUI package. Product names and trademarks identify their respective owners; this independent package is not endorsed by MUI or Google.

Native adaptation and generator: Copyright (c) 2026 Altroo and contributors.
